================================================================================
                           VERSION NUMBERS
================================================================================

Format: X.Y.Z+B
  X = Major (1 = current)
  Y = Minor (0 = current)
  Z = Patch (17 = current)
  B = Build (26 = current, auto-incremented)

Examples:
  1.0.17+26  (current)
  1.0.17+27  (after one build)
  1.0.17+28  (after another build)

To change manually:
  nano pubspec.yaml
  Change: version: 1.0.17+27

================================================================================
                          TROUBLESHOOTING
================================================================================

Problem: Command not found
Solution: chmod +x build_release.sh

Problem: Flutter not found
Solution: flutter --version (or check PATH)

Problem: Build failed
Solution: flutter clean && flutter pub get && ./build_release.sh

Problem: Signing failed
Solution: Check android/key.properties exists

Problem: APK built but AAB failed
Solution: Use APK for testing, AAB is optional
